# DNKN177 – Student Enrollment Management

## Giới thiệu
Module quản lý đăng ký học phần sinh viên, hỗ trợ kiểm tra điều kiện đăng ký, lựa chọn học phần, quản lý lịch sử và theo dõi trạng thái đăng ký.

## Chức năng chính
- Kiểm tra điều kiện đăng ký học phần.
- Lựa chọn nhiều học phần.
- API đăng ký học phần.
- Quản lý lịch sử đăng ký.
- Hiển thị trạng thái và thông báo kết quả.
- Kiểm thử quy trình đăng ký.
