# DNK240 - Quản lý lịch học

## Giới thiệu
Chức năng quản lý lịch học, hỗ trợ tạo, xem và cập nhật lịch học, đồng thời kiểm tra xung đột lịch và lưu lịch sử thay đổi.

## Chức năng chính
- Quản lý lịch học.
- Kiểm tra trùng lịch, xung đột lịch.
- Lưu lịch sử chỉnh sửa lịch học.
- Cung cấp API phục vụ quản lý lịch học.
- Có dữ liệu mẫu và kiểm thử xung đột lịch.

## Công nghệ
- Backend: Node.js, Express.js
- Dữ liệu: JSON
- Kiểm thử: Node.js

## Chạy dự án
```bash
npm install
npm start
```

*Lưu ý: Kiểm tra `package.json` để xác nhận lệnh chạy phù hợp với cấu hình dự án.*
